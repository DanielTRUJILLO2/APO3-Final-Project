# Fruit Quality Classifier

Proyecto final de visión por computador para clasificar la calidad de tomates chonto en tres categorías:

- bueno
- regular
- malo

Además, el sistema estima el tamaño relativo del tomate como pequeño, mediano o grande.

## Modelos

- Random Forest
- SVM
- CNN simple

## Interfaz

La aplicación se desarrollará con Streamlit y permitirá subir una imagen para obtener la predicción de calidad y tamaño.
